# Prepublication vector-results review

Three independent read-only reviews covered core/native/local/public APIs,
the NFS backend, and SMB plus the C/Python adapters and Rust-port adaptations.
Five actionable findings were fixed before the release commit:

| Severity | Defect | Fix and reproducing coverage |
|---|---|---|
| P1 | Python small-file copies collapsed independent WRITE results and retried an already-executed suffix with truncation. | Consume each outcome once, validate its file/offset/count, and preserve original input indices. New mixed-failure test retains a concurrent suffix writer; existing short-write, transport-index and no-replay tests remain. |
| P2 | SMB path recovery appended a replacement file's suffix to an original confirmed prefix after reconnect. | Return the original error with its prefix; reconnect by pathname only before any bytes are confirmed. A live fault replaces the backing inode and kills the session between chunks. |
| P2 | Local SETATTR mapped a later Unsupported error to NotAttempted after truncation had already run. | Preserve Failed after application starts while keeping genuine preflight rejection. Fault coverage checks truncation before chmod failure in both follow modes. |
| P2 | SMB singleton/mixed-handle metadata and SIZE updates classified invalid local paths as dispatched failures. | Validate path encoding and timestamp fields before dispatch or SIZE mutation. Live tests require zero wire requests, healthy siblings, and unchanged protected data. |
| P2 | NFS GETATTR marked quarantined-session requests dispatched before ensure_usable rejected them. | Reject unusable sessions before recording dispatch; existing live quarantine coverage checks empty success, nonempty rejection and zero RPC on NFS minor versions 1 and 2. |

Re-review found no remaining actionable issues in these fixes. Test expectations
were updated where the old aggregate API required prefix inference; no test
scenario was removed. Independent known successes now remain known even if a
concurrent writer later changes their destination.

The source also incorporates main's SMB SDK 0.42.1 and cc 1.11.0 dependency
update. Live SMB and strict default/all-feature checks exercise that cohort.
The original cached loopback benchmark predates this dependency update;
the coordinated release refresh compares current main with the migration.
CI, registry-only application checks and publication provenance must still be
recorded against their actual release commits. This review does not waive them.
